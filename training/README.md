# SmartHouse Qwen LoRA dataset

Этот каталог предназначен для будущего обезличенного датасета LoRA. До накопления и проверки достаточного числа примеров приложение использует system prompt, tool schemas и runtime language guard.

Правила датасета:

- формат JSONL, один учебный диалог на строку;
- только вымышленные названия комнат и устройств;
- никаких HA tokens, паролей, email, имён клиентов и реальных entity_id;
- tool results должны быть синтетическими, но соответствовать реальным схемам;
- ответы на русском не должны содержать необоснованные факты или другой язык;
- действия считаются выполненными только после `success: true`;
- high/medium-risk действия всегда проходят отдельное backend confirmation.

Первым этапом нужно накопить и вручную проверить не менее нескольких сотен разнообразных примеров. Небольшой случайный датасет способен ухудшить базовую модель.
